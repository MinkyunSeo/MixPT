Abstract

Point cloud transformers aim to capture detailed local geometry and relationships across a scene at a manageable computational cost. Two common approaches are window attention and global attention. They differ in how they enable scene-wide interaction, which refers to information exchange among tokens across a scene. Window attention reduces computational cost by restricting self-attention to groups of tokens called windows; in serialized designs, each window contains a fixed number of consecutive tokens from a spatially ordered sequence. Because each block only directly connects tokens within the same window, information exchange across windows relies on changes in window membership across blocks and hierarchical pooling. Global attention, in contrast, directly connects all tokens within a scene, but computing attention over all token pairs can be costly when the number of tokens is large. To balance computational cost and scene-wide interaction, we introduce MixPT, a point transformer that uses a mix of window and global attention blocks in an interleaved schedule, while retaining a single fixed serialization pattern for its window blocks. For scenes with a large number of tokens, MixPT applies global attention to spatially pooled tokens and returns residual updates to the original-resolution stream. Across indoor and outdoor benchmarks, MixPT achieves competitive accuracy with lower latency than representative window and global attention baselines. We further demonstrate the feasibility of scaling the attention stage in depth by repeating the interleaved pattern of window and global attention blocks.

Preliminaries: Revisiting Window and Global Attention

1. Revisiting Window Attention

Window attention reduces computational cost by restricting self-attention to groups of tokens called windows; in serialized designs, each window contains a fixed number of consecutive tokens from a spatially ordered sequence. Because tokens in different windows cannot interact directly, serialized window transformers rely on changes in serialization pattern and hierarchical pooling for cross-window communication. Alternating the serialization pattern changes window membership across blocks, while hierarchical pooling aggregates information at coarser resolutions.

Information propagation through the first five blocks of encoder stage 3 of LitePT on the Waymo validation set.
Green marks tokens reachable from the red-star token; gray marks those not yet reached.

Here, a token is considered reachable if it can be connected to the selected token through preceding attention blocks and hierarchical pooling transitions. We measure this structural reachability from the attention stage input tokens, excluding receptive fields accumulated in the preceding convolutional stages.

LitePT-S did not achieve 100% mean token reachability on the Waymo validation set even in its deepest attention blocks. In contrast, Volt-S has full structural reachability from its first block. These observations motivate introducing global attention early in the stage to establish full structural reachability. MixPT-S therefore places its first global block after two window blocks, while retaining a fixed serialization for its window blocks.

2. Revisiting Global Attention

Global attention achieves full structural reachability, but we ask whether its weights are also broadly distributed across tokens in every block. To this end, we analyze a) how concentrated attention is within each block and b) where a selected query assigns its attention within the scene.

First, normalized attention entropy measures how evenly a query distributes attention over the keys it can attend to: a value of one indicates uniform attention over the available keys, while lower values indicate greater concentration on a subset.

The figure shows higher entropy in the early Volt-S blocks and lower entropy in several later blocks, indicating that the concentration of attention varies across depth.

Second, we visualize the relative attention weights for a selected Volt query to show where attention concentrates within each block. Although each block allowed global interactions, attention for this query tended to concentrate on localized regions in later blocks.

Attention patterns across Volt blocks on the Waymo validation set.
Values of 1 and 10 indicate weights equal to and ten times the uniform weight, respectively.

These two key observations motivate the periodic use of global attention in MixPT-S for direct cross-window information exchange without computing attention between all token pairs in every block.

Method

Architecture Overview

We retain the high-resolution sparse convolutional stages and remaining decoder structure of LitePT. We consolidate LitePT's multiple attention stages into a single stage by removing the intermediate pooling transition and the corresponding decoder upsampling. Within this stage, all window blocks reuse a single fixed serialization pattern, while global attention blocks are periodically interleaved following the WWGWWGWW schedule.

Fixed-Order Window Attention

Unlike PTv3 and LitePT, which vary serialization patterns across blocks, we use a single fixed pattern throughout the attention stage. This allows the serialization and window-index mappings to be reused across window attention blocks. Our default is Trans Z-order (TZ).

We follow LitePT in applying self-attention within serialized windows containing a fixed number of tokens, followed by an MLP. We omit its additional block-entry LayerNorm on the residual stream and use a standard pre-norm design with LayerNorm only before the attention and MLP sublayers.

Interleaved Global Attention with Pooling

A global block enables scene-wide communication across fixed windows. When the number of stage tokens is manageable, we apply global attention directly at the original stage resolution. For large token sets, we apply global attention to spatially pooled tokens and return only the resulting residual updates to the original-resolution stream.

Rotary Positional Encoding for 3D Points

We follow the axial PointROPE formulation used in LitePT, while using an asymmetric allocation of RoPE dimensions across the three spatial axes in our default configurations. Specifically, one-dimensional RoPE is applied independently to the x-, y-, and z-axis subspaces of each attention head's query and key vectors.

Following the instance segmentation setup of LitePT, we used MixPT-S*, which extends MixPT-S with additional attention and convolution blocks.

MixPT-S achieved the lowest latency across all four datasets, reducing latency by 19% to 32% relative to LitePT-S. The gap was larger relative to Volt-S, the global attention baseline, on outdoor datasets where MixPT-S was 2.1 to 6.9× faster. Despite these latency reductions, MixPT-S matched or improved upon LitePT-S in mIoU across all four datasets when evaluated without TTA. MixPT-B and MixPT-L generally improved performance across the evaluated benchmarks.

Latency Breakdown

A key source of efficiency is that MixPT constructs the serialization order and stage layout once and reuses them across window attention blocks. Token reorganization therefore occurs only at stage entry and exit, whereas LitePT repeatedly gathers and scatters tokens across blocks. On nuScenes, these serialization-related operations took 1.01 ms in MixPT-S, compared with 10.61 ms in LitePT-S.

Fixing the serialization pattern reduced latency on both datasets, while leaving mIoU nearly unchanged on SemanticKITTI and decreasing it on ScanNet. Changing two of the eight window blocks to global blocks raised mIoU to 70.0% and 76.0%, respectively, with only a small increase in full-model latency. Overall, periodic global attention improved the accuracy of fixed serialization while preserving its latency advantage over multi-pattern window attention.

Among the eight-block schedules, WWGWWGWW provided a favorable accuracy-latency trade-off on nuScenes and achieved the highest mIoU on ScanNet. Increasing the number of global blocks did not consistently improve accuracy and incurred additional latency on nuScenes, supporting the use of global attention only periodically.

How Much Pooling Should Precede Global Attention?

On Waymo, pooling reduced full-model latency and, at s = 2, even improved mIoU over full-resolution global attention. For s ≥ 2, peak memory during global blocks fell below that of window blocks, while further pooling provided only modest additional reductions in global block memory.
